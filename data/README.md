# Data directory

No customer dataset is included or analyzed in this Week 1 project. The
analysis is intentionally at the research-design stage; see
`../docs/analysis_plan.md` and `../docs/research_sources.csv` for possible
transaction and review sources.

Do not place direct identifiers, sensitive health/skin data, or unapproved
customer extracts in this folder. Before acquiring any candidate dataset,
confirm its license/reuse terms, permitted purpose, and access conditions.
If a synthetic demonstration dataset is added later, label its filename,
metadata, and every report use as synthetic and do not present it as evidence.
